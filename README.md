# PayPal SMB EU Churn — End-to-End ML Pipeline

Predicts which PayPal European SMB merchant accounts are likely to become
dormant (churn) in the next 60-90 days, so the Database Marketing team can
hand a prioritized, precision-ranked list to Sales for proactive retention.

Structure mirrors the Telco Customer Churn MLOps reference project.
See notebooks/EDA.ipynb for exploratory analysis and model comparison.
